# Synkan

Аналог Trello с ИИ-ассистентом. Создавайте доски, приглашайте команду и управляйте задачами вместе с умным ИИ-ассистентом, который анализирует проект, составляет чеклисты, планирует работу и вносит изменения по вашему запросу.

## О проекте

**Synkan** - это приложение, которое позволяет командам управлять проектами на Kanban-досках: создавать доски, колонки, карточки, чеклисты, метки и дедлайны. Ключевая особенность - совместная работа в реальном времени (изменения у всех участников отображаются мгновенно) и встроенный ИИ-ассистент, который умеет самостоятельно изменять и добавлять компоненты доски по текстовым командам пользователя.


---

## Основные возможности

- **Совместная работа в реальном времени** — синхронизация всех изменений доски через SignalR.
- **Интерактивный ИИ-ассистент** — общий чат доски со встроенным агентом. ИИ умеет самостоятельно изменять и добавлять компоненты доски по текстовым командам пользователя.
- **Компоненты карточек** — обложки, метки, чек-листы с отслеживанием прогресса и дедлайны.
- **Фоновые напоминания** — планирование и отправка уведомлений о приближающихся дедлайнах с помощью планировщика Hangfire.
- **Защита от спама** — кастомный Rate Limiter Middleware на базе Redis.
- **Полная наблюдаемость (Observability)** — сгенерированные трассировки, структурированные JSON-логи и системные метрики CLR.

## Запуск в Docker

Полный запуск системы, базы данных и полный стек мониторинга:

1.  Клонируйте репозиторий:
    ```bash
    git clone https://github.com/tynou/synkan.git
    cd synkan
    ```

2. Запустите приложение
    ```bash
    docker compose up -d
    ```

### Доступные сервисы после запуска:
